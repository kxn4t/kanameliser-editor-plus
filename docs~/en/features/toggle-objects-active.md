# Toggle Objects Active

Quickly toggle between GameObject active state and EditorOnly tag.

Executing on an active GameObject adds the EditorOnly tag to hide it in the editor only. Executing again removes the tag and restores the active state.

![Ctrl+G toggles between active (Untagged) and inactive (EditorOnly)](/images/toggle-objects-active/overview-en.png)

## Access

Shortcut: `Ctrl+G`
