# Component Copier

衣装やアバターに付いているコンポーネント（PhysBone、Contact、Constraint、Modular Avatar など）を、別の衣装やアバターへコピーできます。単に設定値をコピーするだけでなく、 **コンポーネント内のオブジェクト参照（ボーン、コライダー、Constraint のソースなど）も、コピー先の対応するオブジェクトへ自動的に差し替えます。**

こんなときに使えます。

- 同じ衣装の更新版や、別アバター対応版へ、PhysBone や Modular Avatar の設定を引き継ぐ
- 衣装の一部のコンポーネントだけを別の衣装へ持っていく

## 使い方

1. メニューから `Tools > Kanameliser Editor Plus > Component Copier` を開く
2. **コピー元** に、設定を持っているオブジェクトを指定する。（Hierarchy 上のオブジェクト、Prefab インスタンス、Project 内の Prefab アセットのいずれも指定可能。指定すると配下のコンポーネントが一覧表示されます）
3. コピーしたいコンポーネントにチェックを入れる
4. **コピー先** に、設定を受け取るシーン上のオブジェクトを指定する。（コピー元とコピー先のオブジェクトの対応付けが自動で行われます）
5. **対応付け** セクションを確認し、要確認（`?`）や未対応（`✖`）の項目があれば、必要に応じて手動で対応先を設定する
6. **適用前チェック** の内容を確認し、問題がなければ **適用** ボタンを押す。（※ Undo で元に戻せます）
7. 適用後に表示される差分チェックの結果を確認し、期待通りにコピーされたか確かめる

::: tip 注意：コピー先に指定できるオブジェクトについて
コピー先には **シーン上のオブジェクト** （Prefab インスタンスや Prefab Stage 内のオブジェクトを含む）のみ指定可能です。Prefab アセットへ直接適用すると Prefab Variant に波及してしまうなど、Undo が難しくなってしまうためです。  
なお、何も変更を行わない「差分チェックのみ」であれば、Prefab アセットも指定できます。
:::

## コンポーネント一覧

コピー元を指定すると、配下のコンポーネントが種類やオブジェクトごとにまとめて表示されます。

- **プリセット**: PhysBone、Contact、Constraint、MA（Modular Avatar）、その他のツール（AAO、TTT など、コピー元に存在するもの）、すべて、でまとめてチェックできます
- **検索**: オブジェクトのパスや型名で部分一致検索が行えます。`.*` ボタンをオンにすると正規表現（例: `Skirt|Hair`）が使用できます
- **その他も表示**: 既定では非表示になっている基本の型（Transform、Renderer、MeshFilter、Animator、VRCAvatarDescriptor、PipelineManager）も選択対象に含めます
- **コピー先にないオブジェクト**: 一覧の末尾には、コピー先に存在しない Prefab や空オブジェクト（アンカーなど）がまとめられます。コピー対象のコンポーネントに必要なものは自動生成され、それ以外もチェックを入れることで追加できます

※リストの行や見出しをクリックすると、該当するオブジェクトが選択され Hierarchy 上でハイライト表示されます。

## 対応付け

コピー元とコピー先のオブジェクトは、**パス、名前、Humanoid ボーンの辞書**（`Hips` と `Hip`、`UpperArm_L` と `Left arm` など）を参照して自動で紐付けられます。`Armature.1` や `.001` といった重複回避の接尾辞や、片側だけに付いた共通の接頭辞・接尾辞も自動で認識・補正されます。

- **曖昧な対応付け**: 類似した名前による対応は自動採用せず、候補として表示します
- **ボーンとその他の区別**: ボーン（SkinnedMeshRenderer が参照する Transform）とそれ以外のオブジェクトは個別に識別して対応付けます
- **不足ボーンの扱い**: コピー先にないボーンは自動作成されません。該当ボーンに紐付くコンポーネントは **保留** 状態になるため、対応付けセクションで手動指定してください
- **手動調整**: 各行では、ドロップダウンから候補を選ぶか、ObjectField に直接オブジェクトを指定できます。「なし」を選択すると対応先なしとして処理されます
- **設定の保持**: 手動で指定した対応は、更新（`↻`）やシーンの変更を行っても保持されます

### コピー元の外への参照について

衣装のコンポーネントが、アバター側のボーンやコライダーを参照している場合、コピー先が別のアバター配下にあれば、 **コピー先アバターの対応するオブジェクトへ自動的に参照を差し替えます。** 対応するオブジェクトが見つからない場合は元の参照を維持します。

※「コピー元の外への参照」グループのトグルで全体の一括切り替えができるほか、行ごとに「そのまま残す」を選択することも可能です。

::: tip アバター内に衣装を置こう
たとえば衣装のコンポーネントをコピーしたい場合、コピー元とコピー先の衣装はそれぞれアバター内に配置してコピーするのがオススメです。  
`MA Mesh Settings` や `MA Mesh Cutter`、`MA Shape Changer` のようなアバターのオブジェクトを指定しがちなコンポーネントの参照も一緒に差し替えられます。
:::

## 設定

| 設定 | 選択肢 | 既定 |
| --- | --- | --- |
| **既存のコンポーネント** | 上書き / 追加（重複させる） / スキップ / 置き換え（削除してからコピー） | **上書き** |
| **足りないオブジェクトを作成** | オン / オフ | **オン** |
| **未解決の参照** | None でコピー / コンポーネントごとスキップ | **None でコピー** |

- **上書き**: コンポーネント自体を作り直さずに値を更新するため、他から該当コンポーネントへ張られている参照が切れません
- **未解決の参照**: 参照先にコピー対応するオブジェクトがない場合の挙動です。「コンポーネントごとスキップ」を選ぶと、ソースのない Constraint やコライダーのない PhysBone といった不完全なコンポーネントの作成を防ぎ、対応付けが完了するまで処理を保留できます

## ネストされた Prefab

コピー元の中にある Prefab（PhysBone 設定用 Prefab、`Head` 直下の帽子など）がコピー先に存在しない場合、オブジェクトを一から作り直すのではなく、**同じ Prefab をコピー先にインスタンス化します。**

この際、Prefab 内のコンポーネントは選択の有無にかかわらずすべてコピーされ、コピー元のインスタンスで変更された値も引き継がれます。不要なコンポーネントのチェックを外しておくと、インスタンス化された後に自動で削除されます。

## 適用前チェックと差分チェック

### 適用前チェック

実行前に以下の処理内容や注意点が事前にリストアップされます。

- 新規・上書き・置き換え・スキップの各件数、および新規作成されるオブジェクト数
- 保留になっているコンポーネントとその理由
- 参照が空（None）になる（または設定によりスキップされる）未解決の参照とその原因
- そのまま保持される「外への参照」
- コンポーネントの置き換え（削除）によって、コピー対象外のコンポーネントからの参照が切れる場合の警告

### 差分チェック

「差分チェックのみ」を実行すると、シーンを変更せずにコピー実行後の期待値と現在の状態を比較できます。また、適用実行後にも同形式で結果が表示され、以下のステータスごとに状態を確認できます。

- 状態区分: 一致 / 値が違う / 参照が違う / 参照が未解決 / コピー先にない / コピー先にだけある

## 注意事項

- **トランスフォームのコピー**: 位置（Position）や回転（Rotation）はローカル値をそのままコピーします。ボーンの初期向きが大きく異なるアバター同士では、コピー後に手動調整が必要になる場合があります
- **Modular Avatar の参照補正**: Merge Armature の対象や Object Toggle / Shape Changer などの参照は、オブジェクト参照だけでなくアバター基準のパス情報も自動で書き換えます
- **PipelineManager について**: PipelineManager をコピー対象に含めると Blueprint ID まで複製されてしまいます。通常はチェックを外して対象外にしてください

## アクセス方法

以下のいずれかの方法でツールを起動できます。

- メインメニュー: `Tools > Kanameliser Editor Plus > Component Copier`
- Hierarchy 右クリック → `Kanameliser Editor Plus > Component Copier > Use as Source / Use as Target`
- Project ビューの Prefab 右クリック → `Kanameliser Editor Plus > Component Copier > Use as Source`
- Inspector（コンポーネントヘッダー右クリック） → `Kanameliser Editor Plus > Copy with Component Copier`（※そのコンポーネントだけをチェックした状態で開きます）
